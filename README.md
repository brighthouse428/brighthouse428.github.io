# BRIGHT HOUSE — Portfolio

Official portfolio for Kang Hyun Woo (Bright House).

Website: https://brighthouse428.github.io/

The main page is a standalone static `index.html`. The design includes project filters, a Korean/English language switch, the artist biography and selected works.

## Images

Place these photos in `assets/` to display them on the site:

- `portrait.webp` — hero portrait and Drift
- `vocal-light.webp` — Trace
- `installation.webp` — visual art
- `motion.webp` — performance
- `duo.webp` — collaborative performance
- `band.webp` — visual archive
- `vocal-orange.webp` — live vocal photo
- `keys.webp` — synthesizer close-up
- `hero.webp` — About portrait

Until these files are uploaded, the site falls back to gradient backgrounds.

## Deployment

In repository Settings → Pages, choose **Deploy from a branch**, branch **main**, folder **/(root)**, and Save.

## Editing

Edit the `works` list inside `index.html` to change project titles, artwork, descriptions, credits and links. Update About and CV in the HTML markup.

No build system is required.
